Cameras are agent tools, not just sensors

A camera becomes more useful to an agent when it is not treated as a passive feed. The agent should be able to inspect device state, capture a photo, record timed video, move pan and tilt, zoom, and interpret the resulting media.

That tool boundary matters. It turns perception into an action loop: look, move, capture, interpret, decide what to inspect next. The camera is no longer just an input stream; it is a controlled instrument.

Physical workflows need recovery paths

Hardware-adjacent systems fail in ordinary ways. Devices disappear, helper tools are missing, controls expose different ranges, recordings need cleanup, and paths need to be delivered back to the user. The agent interface should make those states inspectable before it tries to be clever.
